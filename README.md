## Resume Job Fit AI

Full-stack AI-powered application that evaluates compatibility between resumes and job descriptions using NLP similarity scoring.

### Architecture
Frontend: Next.js (TypeScript) deployed on Vercel  
Backend: Python API (FastAPI/Flask)  
NLP: Embedding-based similarity scoring  
Deployment: Vercel + <backend hosting>

### Features
- Resume upload
- Job description parsing
- Similarity scoring
- Error handling for backend cold starts
